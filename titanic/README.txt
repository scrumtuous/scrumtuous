TITANIC PYTHON + DATA + MACHINE LEARNING COURSE
================================================

HOW TO USE
1. Unzip the project.
2. Open index.html in a web browser.
3. Use the hype landing page to launch any lesson.

CONTENTS
- 15 self-contained HTML lessons
- 1 landing page
- All CSS and JavaScript are embedded in each HTML file
- No build process required
