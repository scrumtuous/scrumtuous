Operation 1

list: Ordered & Changeable

A list is an ordered collection that can grow, shrink, and change. Perfect for a passenger manifest where record order matters.

passengers = [
    "Owen",
    "Anna",
    "Laina"
]

passengers[0] = "Mr. Owen Harris"
passengers.append("John")

print(passengers)
Think: “a sequence of things I may need to add to, remove from, or edit.”

Operation 2

tuple: Ordered & Unchangeable

A tuple is ordered like a list, but once created, its items should not be changed. Use it for values that belong together and should stay fixed.

passenger_class = (
    1,
    "First Class"
)

print(passenger_class[0])

passenger_class[0] = 2
# TypeError: tuple does not support item assignment
QUIZ ALERT
Lists are mutable; tuples are immutable. If you try to assign a new value into a tuple position, Python raises TypeError.

Operation 3

dict: Lookup by Key

A dictionary stores key-value pairs. Instead of asking for “item 3,” you ask for something by name, such as "age" or "fare".

passenger = {
    "name": "Braund, Mr. Owen Harris",
    "age": 22,
    "fare": 7.25
}

print(passenger["age"])
print(passenger["fare"])
Natural CSV shape: one CSV row becomes one dictionary when you use csv.DictReader.

Operation 4

set: Unique Values Only

A set removes duplicates and is excellent when you care about uniqueness or membership rather than order.

ports = [
    "Southampton",
    "Cherbourg",
    "Southampton",
    "Queenstown"
]

distinct_ports = set(ports)

print(distinct_ports)
QUIZ ALERT
A set is for uniqueness, not order. Converting a list to a set removes duplicates, but you should not rely on the original ordering.

Operation 5

Reading a CSV File

csv.DictReader reads each row as a dictionary whose keys come from the CSV header.

import csv

with open("titanic.csv") as f:
    reader = csv.DictReader(f)
    passengers = list(reader)

print(passengers[0])
CSV header➡️dictionary keys CSV row➡️dictionary values
QUIZ ALERT
csv.DictReader returns CSV field values as strings. If a CSV contains 22 or 7.25, you still need int(...) or float(...) before numeric calculations.

🚫 String math

fare1 = "10"
fare2 = "20"

print(fare1 + fare2)
# "1020"

✅ Numeric math

fare1 = float("10")
fare2 = float("20")

print(fare1 + fare2)
# 30.0

Operation 6

Why with open(...) Matters

A context manager automatically closes the file when the block ends — even if an exception happens partway through.

with open("titanic.csv") as f:
    data = f.read()

# file is closed here
QUIZ ALERT
with is not just style. It helps prevent resource leaks, ensures files close on exceptions, and matters for writing because buffered output may still be waiting to be flushed.
Use it for both reading and writing. The same safety benefit applies either way.

Operation 7

Building a Summary Dictionary

A common data-processing pattern is to accumulate a running total in a dictionary. The key identifies the group; the value stores the running total.

fare_totals = {}

for passenger in passengers:
    pclass = passenger["Pclass"]
    fare = float(passenger["Fare"])

    fare_totals[pclass] = (
        fare_totals.get(pclass, 0.0) + fare
    )
QUIZ ALERT
dict.get(key, default) avoids a KeyError the first time a key appears. This manual accumulation pattern is conceptually what pandas groupby(...).sum() will later replace.

Operation 8

Writing to a File

Writing is the mirror image of reading: open the file in write mode, write your output, and let the with block close it safely.

with open("class_summary.txt", "w") as f:
    for pclass, total in fare_totals.items():
        f.write(
            f"Class {pclass}: {total:.2f}\n"
        )
QUIZ ALERT
with is valuable for writing too. Closing promptly helps make sure buffered writes are flushed instead of being left pending.

Mini Lab

Titanic Passenger Summary from CSV

Combine everything: read passenger rows, convert strings to numbers, build summaries, find unique values, and write the results back out.

🎓 Final challenge

Using titanic.csv: read with csv.DictReader inside a with block, total fares by passenger class, build a set of distinct embarkation ports, print totals sorted by class, and write the same summary to titanic_summary.txt.

import csv

with open("titanic.csv") as f:
    reader = csv.DictReader(f)
    passengers = list(reader)

totals = {}
ports = set()

for passenger in passengers:
    pclass = passenger["Pclass"]
    fare = float(passenger["Fare"])

    totals[pclass] = (
        totals.get(pclass, 0.0) + fare
    )

    ports.add(passenger["Embarked"])

for pclass in sorted(totals):
    print(
        f"Class {pclass}: "
        f"{totals[pclass]:.2f}"
    )

print("Ports:", ports)

with open("titanic_summary.txt", "w") as f:
    for pclass in sorted(totals):
        f.write(
            f"Class {pclass}: "
            f"{totals[pclass]:.2f}\n"
        )
