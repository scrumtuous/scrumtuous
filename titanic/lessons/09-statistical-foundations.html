Operation 1

Distribution Shape: Skew

Skew measures asymmetry. A large positive skew means most values are lower, with a long tail stretching toward a smaller number of much larger values.

df["Fare"].skew()

# near 0  -> roughly symmetric
# positive -> long right tail
# negative -> long left tail
Low fares
Moderate
Higher
Very high
Extreme
Many smaller values → a few very large values → long right tail
QUIZ ALERT
Strong positive skew means a long right tail. The mean is typically pulled upward relative to the median. It does not mean the median is larger than the mean.

Operation 2

See the Shape with Buckets

You do not need a plotting library just to get a first feel for shape. pd.cut() can bucket a numeric column into ranges.

(
    pd.cut(df["Fare"], bins=5)
      .value_counts()
      .sort_index()
)
Why this helps: skew gives one summary number; bucket counts let you see how that number arises from the actual distribution.

Operation 3

Correlation with pearsonr()

pearsonr() returns two values: a correlation coefficient r and a p-value p.

from scipy import stats

clean = df[["Age", "Fare"]].dropna()

r, p = stats.pearsonr(
    clean["Age"],
    clean["Fare"]
)

print("r =", r)
print("p =", p)
rDirection and strength of the linear relationship
pHow surprising this result would be if there were no real linear relationship
nSample size matters when judging how stable the result is
QUIZ ALERT
Report both r and p. A correlation coefficient alone does not tell you how much evidence the sample provides for a non-zero linear relationship.

Quiz Connection

Read r and p Together

✅ Careful interpretation

“The sample shows a moderate positive correlation, and the low p-value provides evidence that the relationship is unlikely to be chance alone under the null.”

🚫 Overclaim

“Higher quantity causes higher value in every situation.”

QUIZ ALERT
A low p-value does not prove causal direction. Statistical significance says something about evidence against a null model, not about what caused what.

Operation 4

Correlation Is Not Causation

Even a strong correlation can be produced by a third factor, selection effects, or coincidence.

Ice cream sales ↑↗️ Hot weather↘️ Drowning deaths ↑
Classic lesson: ice cream sales do not cause drowning. Summer heat influences both.
QUIZ ALERT
Even a strong, statistically significant correlation does not prove causation. There may be confounding variables, reverse causality, selection bias, or other explanations.

Operation 5

Testing a Hypothesis

EDA might suggest that two groups differ. A hypothesis test gives you a formal way to ask how compatible the observed difference is with a null hypothesis of no difference.

survivors = df.loc[
    df["Survived"] == 1,
    "Fare"
].dropna()

non_survivors = df.loc[
    df["Survived"] == 0,
    "Fare"
].dropna()

t_stat, p_value = stats.ttest_ind(
    survivors,
    non_survivors,
    equal_var=False
)
EDA sees a difference➡️ Define null hypothesis➡️ Run test➡️ Interpret p-value
QUIZ ALERT
ttest_ind() compares the means of two independent groups. Using equal_var=False avoids assuming the two groups have identical variance.

Operation 6

What the p-value Means

The null hypothesis says the underlying groups do not differ in the way being tested. The p-value tells you how unusual your observed result would be if that null model were true.

H₀No real difference between group means
pHow surprising this result is under H₀
.05A common convention, not a law of nature
QUIZ ALERT
p < 0.05 is a common convention, not a magical truth threshold. A p-value just below .05 may still be fragile, especially in a small or imbalanced dataset.

🎯 Your challenge

The second statement is better.

Quiz Connection

The Small-Sample Caveat

A result can technically cross a significance threshold and still deserve skepticism.

🚫 Too confident

“p = 0.04, so the market insight is established.”

✅ Better

“The result is suggestive, but the smaller group is tiny and the p-value may be unstable.”

QUIZ ALERT
Small, imbalanced groups make borderline p-values less reliable. One unusual observation can materially change the result. Statistical significance is a starting point for more evidence, not the end of the story.

import pandas as pd
from scipy import stats

df = pd.read_csv("titanic.csv")

print("Fare skew:", df["Fare"].skew())

print(
    pd.cut(df["Fare"], bins=5)
      .value_counts()
      .sort_index()
)

clean = df[["Age", "Fare"]].dropna()

r, p = stats.pearsonr(
    clean["Age"],
    clean["Fare"]
)

print("r =", r)
print("p =", p)

survivors = df.loc[
    df["Survived"] == 1,
    "Fare"
].dropna()

non_survivors = df.loc[
    df["Survived"] == 0,
    "Fare"
].dropna()

t_stat, p_value = stats.ttest_ind(
    survivors,
    non_survivors,
    equal_var=False
)

print("t =", t_stat)
print("p =", p_value)
