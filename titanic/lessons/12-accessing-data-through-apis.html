Operation 1

Endpoints & Authentication

An endpoint is a URL the server knows how to handle. Authentication tells the server who or what is making the request.

🚫 No API key

resp = requests.get(
    "http://127.0.0.1:5050/passengers"
)

print(resp.status_code)
# 401

✅ Authenticated

resp = requests.get(
    "http://127.0.0.1:5050/passengers",
    headers={
        "X-API-Key": "titanic-class-key"
    }
)

print(resp.status_code)
# 200
QUIZ ALERT
Authenticate every request. Also, never commit a real production API key into source control. The classroom key is intentionally disposable.

Operation 2

Pagination: One Request, One Page

Most APIs do not send every record at once. You request a page, inspect the metadata, then request the next page.

resp = requests.get(
    url,
    headers=HEADERS,
    params={
        "page": 1,
        "page_size": 5
    }
)

body = resp.json()

# {
#   "page": 1,
#   "page_size": 5,
#   "total_pages": 4,
#   "total_records": 20,
#   "data": [...5 passenger rows...]
# }
QUIZ ALERT
data contains only the current page. A successful 200 response does not mean you have retrieved the entire dataset.

Loop Until Every Page Is Fetched

all_rows = []
page = 1

while True:
    body = fetch_page(
        page,
        page_size
    )

    all_rows.extend(
        body["data"]
    )

    if page >= body["total_pages"]:
        break

    page += 1
Page 1➡️ extend list➡️ Page 2➡️ extend list➡️ until done
QUIZ ALERT
The pagination loop is the client's responsibility. The server answers one page at a time; your code must accumulate every page.

Operation 4

429 Rate Limits: Back Off, Don't Skip

HTTP 429 means the server is asking you to slow down. A well-behaved client waits, then retries.

resp = requests.get(
    url,
    headers=HEADERS,
    params={
        "page": page,
        "page_size": page_size
    }
)

if resp.status_code == 429:
    retry_after = int(
        resp.headers.get(
            "Retry-After",
            1
        )
    )

    time.sleep(retry_after)

    continue
    # retry the SAME page
QUIZ ALERT
This is one of the most important quiz rules: on 429, wait for Retry-After and retry the SAME page. Do not increment the page number, do not skip the data, and do not hammer the endpoint immediately.

🚫 Wrong

if resp.status_code == 429:
    page += 1
    continue

This silently skips a page.

✅ Correct

if resp.status_code == 429:
    time.sleep(retry_after)
    continue

The page number stays unchanged.

Operation 5

A Well-Behaved Client

🔐
Authenticate Send credentials with every request.
📄
Paginate Keep requesting until every page is fetched.
⏳
Back off Honor 429 and Retry-After.
🔁
Retry safely Retry the same failed page.
These aren't optional niceties. Ignoring any one may appear to work during a tiny demo, then fail against a real service under load.

Judgment Call

API or Batch Extract?

An API is not automatically “better” than a file. The right choice depends on the data-access need.

🌐 API fits when...

  • You need current or frequently changing data.
  • You only need a subset of records.
  • You need to trigger an action.
  • Interactive access matters.

📦 Batch extract fits when...

  • You need a large complete dataset.
  • You need it infrequently, such as nightly.
  • Pagination overhead adds no value.
  • You don't want analytics to depend on the source being online at query time.
QUIZ ALERT
API vs extract is a business and engineering judgment, not a technology popularity contest. Fresh subset access favors APIs; large complete periodic datasets often favor batch extracts.

🎓 Final challenge

Write the skeleton of a robust paginated client with authentication and 429 handling.

import time
import requests
import pandas as pd

URL = "http://127.0.0.1:5050/passengers"

HEADERS = {
    "X-API-Key": "titanic-class-key"
}

def fetch_page(page, page_size):
    while True:
        resp = requests.get(
            URL,
            headers=HEADERS,
            params={
                "page": page,
                "page_size": page_size
            }
        )

        if resp.status_code == 429:
            retry_after = int(
                resp.headers.get(
                    "Retry-After",
                    1
                )
            )

            time.sleep(retry_after)
            continue

        resp.raise_for_status()
        return resp.json()

def fetch_all_passengers(page_size=5):
    rows = []
    page = 1

    while True:
        body = fetch_page(
            page,
            page_size
        )

        rows.extend(
            body["data"]
        )

        if page >= body["total_pages"]:
            break

        page += 1

    return rows

rows = fetch_all_passengers()

df = pd.DataFrame(rows)

print(df.head())
print(df.shape)
