Operation 1

Three Prediction Problems

All three learn from known examples and try to predict something unknown, but the thing being predicted has a different shape.

📈
Regression Predicts a number.
Example: predict Fare.
🎯
Classification Predicts a category.
Example: Survived = 0 or 1.
🕰️
Forecasting Predicts a future point in an ordered timeline.
QUIZ ALERT
Regression predicts numeric values; classification predicts categories; forecasting predicts future values along time. Choosing the wrong problem type means choosing the wrong model and metrics.

Forecasting reality check

Two Weeks Is Not a Forecasting Dataset

You already created weekly totals with resample("W"). That gives the right shape for forecasting, but not enough history to forecast responsibly.

🚫 Two weekly points

Not enough history to identify trend, seasonality, or normal variation.

✅ Many historical periods

Now the model has repeated evidence from which to learn temporal structure.

QUIZ ALERT
Having a datetime index does not automatically make forecasting responsible. Forecasting needs enough historical observations to learn something repeatable.
Operation 2

Train/Test Split: Keep the Exam Questions Secret

If the model learns from the same rows you use to evaluate it, the score can look artificially good because the model has already seen the answers.

All known passengers➡️ 70% training+ 30% test➡️ evaluate on unseen rows 
from sklearn.model_selection import (
    train_test_split
)

X_train, X_test, y_train, y_test = (
    train_test_split(
        X,
        y,
        test_size=0.3,
        random_state=42
    )
)
QUIZ ALERT
test_size=0.3 holds back 30% for evaluation. random_state=42 makes the split reproducible so the same rows land in train and test each run.

✂️ Your challenge

Why is evaluating only on the training set misleading?

Because the model has already learned from those rows.

The test set gives a better estimate of how the model
performs on data it has not seen before.

Operation 4

MAE & RMSE: Two Ways to Measure Regression Error

MAE Average absolute error in the original units.
RMSE Also in original units, but punishes large misses more heavily.
RMSE ≥ MAE For the same prediction set. 
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error
)

mae = mean_absolute_error(
    y_test,
    preds
)

rmse = mean_squared_error(
    y_test,
    preds
) ** 0.5
QUIZ ALERT
MAE is easier to explain as the typical error size. RMSE penalizes large errors more heavily. For the same predictions, RMSE will be at least as large as MAE.

📏 Your challenge

If MAE = 12 and RMSE = 28, what does the much larger RMSE suggest?

There are likely some relatively large prediction errors.

RMSE gives those large misses extra weight, so it rises
more than MAE.
Quiz Connection

Every Metric Needs a Baseline

A model score is not meaningful in isolation. You need to compare it to something simple.

from sklearn.dummy import (
    DummyRegressor
)

baseline = DummyRegressor(
    strategy="mean"
).fit(
    X_train,
    y_train
)

baseline_preds = baseline.predict(
    X_test
)

baseline_mae = mean_absolute_error(
    y_test,
    baseline_preds
)

✅ Useful model

Model MAE = 18
Baseline MAE = 31

The trained model clearly improves on the naive strategy.

🚫 “Smart” but useless

Model MAE = 31
Baseline MAE = 30

The trained model is worse than always predicting the training mean.

QUIZ ALERT
LinearRegression should be evaluated against a naive baseline such as DummyRegressor(strategy="mean"). A model that does not beat the baseline is not adding useful predictive value.

👑 Your challenge

Your regression model has MAE 20. The DummyRegressor baseline has MAE 17. Which model is better?

The DummyRegressor baseline is better.

Lower MAE is better because it means smaller average
prediction errors.

Model

Sounds okay until you compare it.

Majority-class baseline

QUIZ ALERT
Accuracy only becomes meaningful next to a baseline. A model scoring 50% can be worse than a classifier that always predicts the majority class.

Operation 7

Investigate Why a Model Misses

A weak model is not necessarily a coding failure. The chosen features may simply not contain enough predictive signal.

results = X_test.copy()

results["actual"] = y_test
results["predicted"] = preds

print(results)
Look row by row. Are errors clustered in one passenger class? Are extreme fares causing misses? Is there a subgroup with different behavior?
QUIZ ALERT
If one subgroup follows a different relationship, a single global model may struggle. Poor baseline improvement can signal weak features, subgroup-specific logic, or missing information — not merely “bad machine learning code.”

One Pattern, Three Metrics

What Each Evaluation Number Is For

MAE Regression: average absolute error. Easy stakeholder explanation.
RMSE Regression: emphasizes larger misses more heavily.
Accuracy Classification: fraction of predictions that are correct.
QUIZ ALERT
MAE and RMSE are regression metrics; accuracy is a classification metric. None is inherently “good” or “bad” without scale, context, and a baseline.

🎓 Final challenge

Write a compact regression workflow that splits the data, trains LinearRegression, calculates MAE and RMSE, and compares against a mean-predicting baseline.

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.dummy import DummyRegressor
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error
)

data = df[[
    "Age",
    "Pclass",
    "Fare"
]].dropna()

X = data[[
    "Age",
    "Pclass"
]]

y = data["Fare"]

X_train, X_test, y_train, y_test = (
    train_test_split(
        X,
        y,
        test_size=0.3,
        random_state=42
    )
)

model = LinearRegression().fit(
    X_train,
    y_train
)

preds = model.predict(X_test)

mae = mean_absolute_error(
    y_test,
    preds
)

rmse = mean_squared_error(
    y_test,
    preds
) ** 0.5

baseline = DummyRegressor(
    strategy="mean"
).fit(
    X_train,
    y_train
)

baseline_preds = baseline.predict(
    X_test
)

baseline_mae = mean_absolute_error(
    y_test,
    baseline_preds
)

print("Model MAE:", mae)
print("Model RMSE:", rmse)
print("Baseline MAE:", baseline_mae)
