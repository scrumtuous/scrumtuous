Operation 1

Variables & Data Types

A variable gives a value a name. Python is dynamically typed, so you don't declare the type first — Python figures it out from the value.

Four beginner types: str = text, int = whole number, float = decimal number, bool = True/False.
name = "Braund, Mr. Owen Harris"  # str
pclass = 3                        # int
fare = 7.25                       # float
survived = False                  # bool

print(type(fare))
# <class 'float'>

We can also keep all of those values together in a passenger dictionary:

passenger = {
    "name": "Braund, Mr. Owen Harris",
    "pclass": 3,
    "sex": "male",
    "age": 22,
    "fare": 7.25,
    "ticket_purchase_date": "1912-03-10",
    "survived": 0
}

Operation 2

if / elif / else

Control flow lets Python choose what to do based on a condition. Think: “If this passenger is a child, do one thing. Otherwise, do something else.”

age = 22

if age < 18:
    print("Child passenger")
elif age < 65:
    print("Adult passenger")
else:
    print("Senior passenger")
Why elif? Use it when the choices are mutually exclusive — once one branch matches, Python skips the rest.

Operation 3

for Loops

A for loop visits every item in a known collection. In data work, this is one of the most common things you'll ever do.

passengers = [
    {"name": "Owen", "age": 22, "fare": 7.25},
    {"name": "Anna", "age": 38, "fare": 71.28}
]

for passenger in passengers:
    print(passenger["name"])

Output:

Owen
Anna

Operation 4

Accumulating a Total

Loops become especially useful when you want to add something up — fares, passengers, survivors, or any other running total.

passengers = [
    {"name": "Owen", "fare": 7.25},
    {"name": "Anna", "fare": 71.28}
]

total = 0.0

for passenger in passengers:
    total += passenger["fare"]

print(f"Total fares: {total:.2f}")
Total fares: 78.53

Operation 5

while Loops

A while loop keeps repeating as long as a condition remains true. They're useful, but less common than for loops in everyday data work.

passengers = ["Owen", "Anna", "Laina"]

i = 0

while i < len(passengers):
    print(passengers[i])
    i += 1
⚠️ Infinite-loop alert: if you forget i += 1, i never changes and the loop may run forever.
