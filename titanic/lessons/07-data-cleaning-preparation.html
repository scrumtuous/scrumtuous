Operation 2

Missing Values Need Different Decisions

There is no universal “fill missing values” rule. The correct action depends on what the field means and what information is available.

🗑️
Drop Use when the value is required and cannot be reconstructed reliably.
🧮
Recompute Use when the missing value can be derived exactly from other trustworthy fields.
🔁
Backfill Use when the same fact is known elsewhere for the same entity. 
# Example 1: age missing and not reconstructable
df = df[df["Age"].notna()]

# Example 2: fare-per-person missing but derivable
m = df["FarePerPerson"].isna()

df.loc[m, "FarePerPerson"] = (
    df.loc[m, "Fare"] /
    df.loc[m, "FamilySize"]
)

# Example 3: passenger surname known elsewhere
df["Surname"] = (
    df.groupby("FamilyId")["Surname"]
      .transform("first")
)
QUIZ ALERT
“Drop it,” “recompute it,” and “backfill it” can all be correct. The right answer depends on whether the missing value is unreconstructable, derivable, or known elsewhere.

Operation 3

Dates: Don't Guess

A value like 03/04/1912 could mean March 4 or April 3. The characters alone do not tell you which.

# Surrounding records:
# P001 -> 1912-03-03
# P002 -> 03/04/1912
# P003 -> 1912-03-05

# Context suggests P002 is 1912-03-04,
# but only if the sequence is trustworthy.

df["ticket_purchase_date"] = pd.to_datetime(
    df["ticket_purchase_date"],
    format="mixed",
    dayfirst=False
)
QUIZ ALERT
Never resolve an ambiguous date merely by assuming a regional convention. Use trustworthy context such as surrounding records or the source system. A wrong conversion silently corrupts the data.
Important: nearby rows can help only when that sequence is known to be meaningful. If the dataset may be unsorted, go back to the source rather than inventing certainty.

Operation 4

Normalize Categories Carefully

Generic string functions can create new inconsistencies while fixing old ones. Explicit mappings are often safer for business categories.

🚫 Generic transformation

df["Embarked"] = (
    df["Embarked"]
      .str.capitalize()
)

This may be fine for some values, but generic transformations do not understand your business vocabulary.

✅ Explicit mapping

CANONICAL = {
    "southampton": "Southampton",
    "s": "Southampton",
    "cherbourg": "Cherbourg",
    "c": "Cherbourg",
    "queenstown": "Queenstown",
    "q": "Queenstown"
}

df["Embarked"] = (
    df["Embarked"]
      .str.strip()
      .str.lower()
      .map(CANONICAL)
)
QUIZ ALERT
Transform, then validate. After canonicalizing categories, check .unique() to make sure only the expected values remain.
df["Embarked"].unique()

Operation 5

Duplicates vs Outliers

An exact duplicate and an extreme value are not the same kind of problem.

👯 Exact duplicate

If two rows are truly identical and one is accidental, dropping the duplicate is usually safe.

df = df.drop_duplicates()

🚩 Outlier

An extreme fare or age may be wrong — or it may be a real unusual passenger. Flag it first.

high_fare = (
    df["Fare"] >
    df["Fare"].quantile(.75) * 5
)

outliers = df.loc[high_fare]
QUIZ ALERT
Outlier does not mean error. Without investigation, deleting an extreme value can destroy legitimate information. Flag it, document it, and investigate.

Operation 6

Cleaning Is a Series of Decisions

Good cleaning is not “apply one function everywhere.” Each correction needs its own reason.

Measure problem➡️ Understand meaning➡️ Choose fix➡️ Validate result➡️ Document decision
QUIZ ALERT
The reasoning matters as much as the code. A cleaning action should be justified by what is actually knowable from the data or source system.

import pandas as pd

df = pd.read_csv("titanic-messy.csv")

# Inspect first
print(df.isna().sum())
print("Duplicates:", df.duplicated().sum())
print(df["Embarked"].unique())

# Canonical category mapping
PORTS = {
    "southampton": "Southampton",
    "s": "Southampton",
    "cherbourg": "Cherbourg",
    "c": "Cherbourg",
    "queenstown": "Queenstown",
    "q": "Queenstown"
}

df["Embarked"] = (
    df["Embarked"]
      .str.strip()
      .str.lower()
      .map(PORTS)
)

# Remove exact duplicates
df = df.drop_duplicates()

# Parse date only after ambiguity is resolved
df["ticket_purchase_date"] = pd.to_datetime(
    df["ticket_purchase_date"],
    format="mixed"
)

# Flag, don't delete, extreme fares
q3 = df["Fare"].quantile(.75)

df["fare_outlier"] = (
    df["Fare"] > q3 * 5
)

# Validate category cleanup
print(df["Embarked"].unique())
