Operation 1

Match the Chart to the Question

The first visualization decision is not color or style. It is choosing the right chart type for the question.

📊
Bar chart Compare amounts across categories.
📈
Line chart Show a trend across ordered time.
✨
Scatter plot Show the relationship between two numeric variables.
QUIZ ALERT
Chart choice comes before styling. Bars compare category magnitudes, lines show ordered trends, and scatter plots show relationships between two numeric variables. Pie charts become difficult to compare once they have many slices.

Operation 2

Build an Honest Bar Chart

Bars encode magnitude through length, so the baseline matters enormously.

import matplotlib.pyplot as plt

survival = (
    df.groupby("Pclass")["Survived"]
      .mean()
)

fig, ax = plt.subplots()

ax.bar(
    survival.index,
    survival.values
)

ax.set_ylim(bottom=0)

ax.set_title(
    "Survival Rate by Passenger Class"
)

ax.set_xlabel("Passenger Class")
ax.set_ylabel("Survival Rate")
Survival Rate by Passenger Class
Example mini-chart rendered in the page. The bar baseline begins at zero.
QUIZ ALERT
For bar charts, the y-axis should start at zero. Because bar length represents magnitude, truncating the baseline exaggerates differences visually.

Operation 3

Titles & Labels Should Explain the Chart

A reader should not need your notebook or code to understand what a chart is showing.

🚫 Weak

ax.set_title("Chart 1")
ax.set_xlabel("X")
ax.set_ylabel("Y")

✅ Clear

ax.set_title(
    "Average Fare by Passenger Class"
)

ax.set_xlabel("Passenger Class")
ax.set_ylabel("Average Fare")
QUIZ ALERT
Titles and labels should be specific. Include units where they matter, and make the finding understandable without requiring the code.

Operation 4

Build a Line Chart for Time

Line charts are for ordered sequences, especially time. The connecting line implies continuity.

by_week = (
    df.set_index("ticket_purchase_date")
      ["Fare"]
      .resample("W")
      .sum()
)

fig, ax = plt.subplots()

ax.plot(
    by_week.index,
    by_week.values,
    marker="o"
)

ax.set_title(
    "Total Titanic Fare by Ticket-Purchase Week"
)

ax.set_xlabel("Week")
ax.set_ylabel("Total Fare")
Total Titanic Fare by Ticket-Purchase Week
Markers make each weekly observation easier to read.
QUIZ ALERT
Line charts imply ordered continuity. Use them when the x-axis has a meaningful order such as time. Do not connect unrelated categories merely because a line looks attractive.

Operation 5

Scatter Plot: Two Numeric Variables

Each point represents one observation. The shape of the cloud helps you see whether two numeric variables move together.

first_class = df.loc[
    df["Pclass"] == 1
]

fig, ax = plt.subplots()

ax.scatter(
    first_class["Age"],
    first_class["Fare"]
)

ax.set_title(
    "First-Class Passenger Age vs Fare"
)

ax.set_xlabel("Age")
ax.set_ylabel("Fare")
First-Class Passenger Age vs Fare
One dot per passenger. Filtering to one class avoids mixing very different fare regimes.
QUIZ ALERT
Filter before plotting when mixing segments would obscure the relationship. A scatter plot should make the numeric relationship clearer, not blend unrelated subgroups into one confusing cloud.

Operation 6

Build a Misleading Chart on Purpose

A chart can contain completely accurate numbers and still give a dishonest visual impression.

avg_fare = (
    df.groupby("Pclass")["Fare"]
      .mean()
)

fig, ax = plt.subplots()

ax.bar(
    avg_fare.index,
    avg_fare.values
)

ax.set_ylim(bottom=10)
# Misleading if the smallest bar
# is only slightly above 10.

🚫 Truncated baseline

Differences appear much larger than they really are.

✅ Honest baseline

The same values, but bar length remains proportional to magnitude.

QUIZ ALERT
Technically correct axis labels can still create a misleading chart. If the bar baseline is truncated, the visual language “length = value” is broken.

Critique Checklist

Can Someone Read the Chart Honestly?

1️⃣ Does the chart type match the question?
2️⃣ Does the axis honestly represent magnitude?
3️⃣ Are the title and axis labels specific?
4️⃣ Are units included where they matter?
5️⃣ Would a reader unfamiliar with the data reach the right conclusion?
6️⃣ Have different segments been mixed in a way that obscures the story?
QUIZ ALERT
A visualization should be clear and honest, not merely technically valid. Always critique the impression the chart creates, not just whether the numbers printed on it are correct.
