Step 1

What Is Classification?

Classification means predicting which category an observation belongs to.

📈
Regression Predict a number, like Fare.
🎯
Classification Predict a category, like Survived = 0 or 1.
🕰️
Forecasting Predict a future value over time.
KEY IDEA
Titanic survival is a binary classification problem. The model predicts one of two categories: 0 = did not survive, 1 = survived.

🌸 Quick check

Why isn't predicting Survived a regression problem?

Because Survived is a category with two possible
classes: 0 or 1.

We are choosing a class, not predicting an arbitrary
continuous number.

Step 3

Prepare the Data

Machine-learning models need clean inputs. Numeric columns may need missing-value handling, and text categories must be converted into numeric representations.

Numeric features

Age
Fare

Fill missing values, often with the median.

Categorical features

Sex
Embarked
Pclass

Encode categories, often with one-hot encoding.

from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder
from sklearn.pipeline import Pipeline

numeric_features = [
    "Age",
    "Fare"
]

categorical_features = [
    "Sex",
    "Embarked",
    "Pclass"
]

numeric_pipeline = Pipeline([
    (
        "imputer",
        SimpleImputer(strategy="median")
    )
])

categorical_pipeline = Pipeline([
    (
        "imputer",
        SimpleImputer(strategy="most_frequent")
    ),
    (
        "encoder",
        OneHotEncoder(handle_unknown="ignore")
    )
])

preprocessor = ColumnTransformer([
    (
        "numeric",
        numeric_pipeline,
        numeric_features
    ),
    (
        "categorical",
        categorical_pipeline,
        categorical_features
    )
])
KEY IDEA
The model should not be expected to understand strings such as "female" or "Cherbourg" directly. The preprocessing step converts them into a numeric form the model can learn from.
Step 4

Split the Passengers into Train & Test Sets

We let the model learn from one set of passengers, then test it on different passengers it has never seen.

All passengers➡️ 70% TRAIN+ 30% TEST 
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = (
    train_test_split(
        X,
        y,
        test_size=0.30,
        random_state=42,
        stratify=y
    )
)
KEY IDEA
The test set is the exam. If the model trains on those rows first, the evaluation is no longer a fair measure of generalization.
Why stratify=y? It helps preserve roughly the same survivor/non-survivor proportions in both train and test sets.

✂️ Quick check

What does test_size=0.30 mean?

30% of the rows are held back for testing.

The model trains on the remaining 70%.
Step 5

Start with a Dumb Baseline

Before celebrating a machine-learning model, ask whether it can beat the simplest possible strategy.

from sklearn.dummy import DummyClassifier
from sklearn.metrics import accuracy_score

baseline = DummyClassifier(
    strategy="most_frequent"
)

baseline.fit(
    X_train,
    y_train
)

baseline_preds = baseline.predict(
    X_test
)

baseline_accuracy = accuracy_score(
    y_test,
    baseline_preds
)
KEY IDEA
DummyClassifier(strategy="most_frequent") always guesses the most common class. Your real classifier should beat this baseline before you claim it has learned anything useful.

🤔 Quick check

If a real classifier has 74% accuracy and the DummyClassifier has 78%, which one is better?

The DummyClassifier is better.

The trained model is not adding useful predictive value
if it cannot beat the naive baseline.
Step 6

Train a Logistic Regression Classifier

Logistic Regression is one of the best first classification models because it is simple, fast, and interpretable.

from sklearn.linear_model import LogisticRegression

model = Pipeline([
    (
        "preprocessor",
        preprocessor
    ),
    (
        "classifier",
        LogisticRegression(
            max_iter=1000
        )
    )
])

model.fit(
    X_train,
    y_train
)
KEY IDEA
Despite its name, Logistic Regression is commonly used for classification. Here it learns to predict the two survival classes.

🤖 Quick check

What does model.fit(X_train, y_train) do?

It lets the model learn patterns connecting the
training features in X_train to the known answers
in y_train.

KEY IDEA
Accuracy tells you how often the model was right overall. It does not tell you what kind of mistakes it made.

✅ Quick check

Step 9

Why Accuracy Is Not the Whole Story

Two models can have the same accuracy and still make very different kinds of mistakes.

Model A

Misses mostly survivors.

Model B

Misses mostly non-survivors.

The overall percentage correct may be identical, but the error pattern is not.

NEXT BIG IDEA
To understand the mistakes, we need more than one number. We need to count actual vs predicted classes separately.

Step 12

Accuracy Comes From the Matrix Too

TN + TP÷ TN + FP + FN + TP= Accuracy 
# Example matrix:
# TN = 90
# FP = 15
# FN = 20
# TP = 55

accuracy = (
    (90 + 55)
    /
    (90 + 15 + 20 + 55)
)

# 145 / 180
# ≈ 0.806
BIG CONNECTION
The confusion matrix contains more information than accuracy. Accuracy is just one summary calculated from those four boxes.
Step 13

Visualize the Matrix

from sklearn.metrics import (
    ConfusionMatrixDisplay
)

ConfusionMatrixDisplay.from_predictions(
    y_test,
    predictions,
    display_labels=[
        "Died",
        "Survived"
    ]
)
This is often the first classification visualization students should learn. It immediately shows whether the model is making more false positives or false negatives.

🔎 Think like an analyst

If the matrix has many false negatives, what kind of passenger is the model failing to identify?

Passengers who actually survived but whom the model
predicted would not survive.

Put It All Together

import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import OneHotEncoder
from sklearn.pipeline import Pipeline

from sklearn.linear_model import LogisticRegression
from sklearn.dummy import DummyClassifier

from sklearn.metrics import (
    accuracy_score,
    confusion_matrix,
    ConfusionMatrixDisplay
)

df = pd.read_csv("titanic.csv")

X = df[
    ["Pclass", "Sex", "Age", "Fare", "Embarked"]
]

y = df["Survived"]

numeric_features = [
    "Age",
    "Fare"
]

categorical_features = [
    "Sex",
    "Embarked",
    "Pclass"
]

numeric_pipeline = Pipeline([
    (
        "imputer",
        SimpleImputer(strategy="median")
    )
])

categorical_pipeline = Pipeline([
    (
        "imputer",
        SimpleImputer(strategy="most_frequent")
    ),
    (
        "encoder",
        OneHotEncoder(handle_unknown="ignore")
    )
])

preprocessor = ColumnTransformer([
    (
        "numeric",
        numeric_pipeline,
        numeric_features
    ),
    (
        "categorical",
        categorical_pipeline,
        categorical_features
    )
])

X_train, X_test, y_train, y_test = (
    train_test_split(
        X,
        y,
        test_size=0.30,
        random_state=42,
        stratify=y
    )
)

baseline = DummyClassifier(
    strategy="most_frequent"
)

baseline.fit(
    X_train,
    y_train
)

baseline_preds = baseline.predict(
    X_test
)

print(
    "Baseline accuracy:",
    accuracy_score(
        y_test,
        baseline_preds
    )
)

model = Pipeline([
    (
        "preprocessor",
        preprocessor
    ),
    (
        "classifier",
        LogisticRegression(
            max_iter=1000
        )
    )
])

model.fit(
    X_train,
    y_train
)

predictions = model.predict(
    X_test
)

print(
    "Model accuracy:",
    accuracy_score(
        y_test,
        predictions
    )
)

print(
    confusion_matrix(
        y_test,
        predictions
    )
)

ConfusionMatrixDisplay.from_predictions(
    y_test,
    predictions,
    display_labels=[
        "Died",
        "Survived"
    ]
)
