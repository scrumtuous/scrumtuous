A DataFrame is a table. A Series is one labeled column of that table.

Operation 3

.iloc vs .loc

These two names look similar but mean different things. Memorize the distinction early.

🔢
.iloc = integer position

Think list-style position: first row, second row, etc.

df.iloc[0]
🏷️
.loc = labels / conditions

Use row labels or Boolean conditions.

df.loc[df["Sex"] == "female"]
QUIZ ALERT
.iloc is position-based; .loc is label/condition-based. This distinction is a frequent source of pandas mistakes.

Operation 4

Boolean Filtering

A Boolean condition creates one True/False value per row. pandas keeps the rows where the condition is True.

df.loc[
    df["Sex"] == "female",
    ["Name", "Age", "Fare"]
]

This says:

Check each row➡️ Keep females➡️ Return Name, Age, Fare
QUIZ ALERT
.loc[condition, columns] is the clear, safe pattern when filtering rows and selecting columns together. It is especially preferable when assignment may follow.

🌷 Your challenge

Quiz Connection

Avoid Chained Indexing

Some pandas expressions seem to work but are less robust, especially when you later modify the filtered result.

🚫 Chained indexing

child_df = (
    df[df["Age"] < 18]
    [["Name", "Age"]]
)

child_df["Child"] = True

✅ Clearer with .loc

child_df = df.loc[
    df["Age"] < 18,
    ["Name", "Age"]
].copy()

child_df["Child"] = True
QUIZ ALERT
Chained indexing can produce a view or a copy, so later assignment may be ambiguous. This is why pandas may warn with SettingWithCopyWarning. Using .loc makes the intent clearer and safer.

Operation 5

groupby(): Yesterday's Loop in One Line

This is one of the biggest Day 2 payoffs. groupby() partitions rows into groups and then applies an aggregation such as sum() within each group.

Plain Python

totals = {}

for passenger in passengers:
    key = passenger["Pclass"]
    fare = float(passenger["Fare"])

    totals[key] = (
        totals.get(key, 0.0) + fare
    )

pandas

df.groupby("Pclass")["Fare"].sum()
QUIZ ALERT
groupby() is conceptually the same as manual dictionary accumulation. It groups rows by the chosen key and performs the requested aggregation within each group. Matching totals are expected, not a coincidence.

✨ Your challenge

Calculate the average age for each passenger class.

df.groupby("Pclass")["Age"].mean()
Operation 6

Filter, Then Aggregate

pandas operations compose naturally. Read a chain top to bottom: filter first, then group, then aggregate.

(
    df.loc[df["Sex"] == "female"]
      .groupby("Pclass")["Fare"]
      .mean()
)
Female passengers➡️ Group by class➡️ Average fare

Important Reality Check

What pandas Does NOT Remove

pandas makes operations shorter. It does not magically make bad data correct.

🚫 Looks numeric, but isn't

# maybe dtype: object
# values could contain strings

✅ Check first

df.info()

QUIZ ALERT
groupby(...).sum() only gives meaningful numeric results if the underlying column is actually numeric and semantically valid. pandas removes bookkeeping, not the need to understand your data.
