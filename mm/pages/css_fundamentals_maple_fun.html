01 / A fresh layer

Same pancakes. Better presentation.

CSS means Cascading Style Sheets. The login page keeps its semantic HTML while CSS changes its colors, typography, spacing, and layout. Beaver handles structural integrity; Raccoon is already asking for a lavender button.

One rule consists of a selector and a declaration block. Each declaration has a property and value, separated by a colon and usually ending in a semicolon.

.field label {
  font-size: 0.875rem;
  font-weight: 600;
  color: #333;
}
/* selector: .field label
   declaration: color: #333; */

The space in .field label means “labels anywhere inside an element with class field.” CSS comments use /* ... */. At-rules such as @media add conditional rules.

The syrup did not arrive

You edit styles.css but the page stays unstyled. What do you inspect before changing selectors?

Reveal solution and reasoning

Check the link’s href and relative path, confirm the filename and extension, save both files, then reload. In DevTools, inspect whether the stylesheet loaded. A correct rule in a file the browser never loaded cannot apply.

03 / A fresh layer

Selectors: choose the right pancake

SelectorMatchesSpecificity
inputEvery input element0-0-1
.fieldElements with class="field"0-1-0
.field inputInputs inside a field wrapper0-1-1
#usernameThe element whose id is username1-0-0

First ask whether both selectors actually match the same element. A rule on a wrapper and a rule on its child are not a direct conflict for properties such as display.

<div class="field">
  <input id="username">
</div>
/* .field matches the div; #username matches the input. */
The supplied quiz’s specificity example assumes both selectors target the same element. If .field is on the wrapper and #username is on its input, both display declarations can apply independently. Always inspect the actual DOM.
04 / A fresh layer

Specificity: who gets the last pancake?

When ordinary author rules in the same cascade layer compete for the same property on the same element, higher specificity wins. Compare ID, class, and type counts from left to right. A later rule wins a tie, not a battle with a higher-specificity selector.

The specificity syrup showdownEdit · Run · Observe

Bad assumption: “My blue rule is last, so blue wins.” Observed result: red wins while the ID rule is present. Why: 1-0-0 outranks 0-1-1. Fix: use reusable classes and avoid unnecessarily strong selectors.

QUIZ ALERTSprint 9 question 2 tests ID versus class specificity. Under the stated same-element, same-cascade conditions, the ID wins regardless of source order. Specificity is part of the cascade, not the entire cascade: origin, importance, and layers are considered first.

Quick stack check

For the same input, which normal rule wins in the same layer?

Avoid reaching for !important as your first fix. It changes cascade importance rather than adding specificity. It can make later overrides harder to understand.
05 / A fresh layer

Maple colors and font stacks

color changes text. background changes the element’s backdrop. Named colors, hexadecimal, and RGB are different ways to describe a color.

color: steelblue;             /* a named color: #4682b4 */
color: #1e6fa8;               /* hex */
color: rgb(30, 111, 168);      /* same color as #1e6fa8 */
background: rgba(30, 111, 168, 0.5); /* 50% alpha */

Alpha allows the backdrop to show through. RGBA is one option; modern RGB syntax and alpha hex can also express transparency. opacity fades the whole element, including its children, which is a different effect.

Raccoon’s color kitchenEdit · Run · Observe

A font stack tries family names in order, then falls back. system-ui, sans-serif uses a system UI font with a generic fallback, without downloading a font. Common font weights are 400 for regular and 700 for bold, although availability depends on the font.

rem uses the root font size: with a 16px root, 0.875rem is 14px. This makes text scale with root-size changes. Browser zoom also scales px text; “px never scales” would be misleading.

Choose readable foreground/background pairs. For typical body text, WCAG AA uses a contrast ratio of at least 4.5:1; large text uses 3:1. A maple-gold button may need dark text rather than white. Test colors instead of assuming a bright color is readable.
06 / A fresh layer

The four layers of the box model

Think of the form as a pancake delivery box: content inside, protective padding, the box edge, then space between this box and the next.

Margin: outside the border
Border
Padding: inside the border
Content: text and controls
  • Content: text or child elements.
  • Padding: space between content and border.
  • Border: the edge around content and padding.
  • Margin: spacing outside the border.
form {
  margin: 24px;
  border: 2px solid #a46a2e;
  padding: 32px;
}

In DevTools, select the form and look for its box-model panel. It shows the layers as actual computed dimensions. Margin can interact with surrounding layout, so measure rather than judging by the screenshot alone.

07 / A fresh layer

The 428px pancake problem

Under content-box, width describes only the content. A 360px width with 32px padding on each side and 2px borders occupies 428px before margin: 360 + 64 + 4.

Under border-box, that declared 360px includes content, padding, and border. The content becomes 292px; margins still remain outside the declared width.

Measure the box, then fix itEdit · Run · Observe
*, *::before, *::after {
  box-sizing: border-box;
}

Calculate before you inspect

A content-box element is 200px wide with 20px padding and a 3px border on each side. What width does its border box occupy? What if you switch to border-box?

Reveal solution and reasoning

Content-box: 200 + 40 + 6 = 246px. Border-box: 200px total, with 154px left for content. Margin is excluded in both cases.

08 / A fresh layer

Flexbox: center and stack

display: flex makes an element a flex container; its direct children become flex items. The main axis follows flex-direction. The cross axis runs perpendicular to it.

Row

The default. The main axis runs horizontally in ordinary horizontal writing mode.

Column

The main axis runs vertically. Perfect for stacking form fields.

Gap

One consistent space between children, without a margin on each one.

body {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}
main {
  flex: 1;
  display: flex;
  justify-content: center; /* main axis */
  align-items: center;     /* cross axis */
}
form {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

The body’s column layout puts header, main, and footer in order. main { flex: 1; } lets the main area grow into remaining space. With the main container’s default row direction, justify-content centers the form horizontally and align-items centers it vertically. Change the direction and the axes swap.

09 / A fresh layer

One breakpoint, two breakfasts

Desktop gets a floating card. A narrow screen gets an edge-to-edge form. A media query asks about the viewport, not the physical device name.

@media (max-width: 480px) {
  main { padding: 0; }
  form {
    max-width: none;
    border: none;
    border-radius: 0;
  }
}

The rules apply at 480 CSS pixels or below, including exactly 480px. The width: 100% in the base form rule lets removing its max-width stretch it. Without an appropriate base width, removing max-width alone does not guarantee edge-to-edge layout.

The responsive breakfast counterEdit · Run · Observe

Use the slider to make the iframe’s viewport 900px, 480px, and 375px. A horizontal scrollbar lets you inspect a wide preview on a smaller screen. Watch the border and radius disappear at the breakpoint. This is a real iframe viewport, rather than a scaled screenshot.

The breakpoint looks broken

Your rule is correct but the form remains rounded at 375px. Which three things do you check?

Reveal solution and reasoning

Confirm the media query uses max-width, verify the viewport width and meta viewport, and inspect whether a later or higher-priority rule overrides the property. Check the browser’s Styles panel for crossed-out declarations.

10 / A fresh layer

Lab 02: style the same login page

Keep Lab 01’s semantic HTML. The supplied Lab 02 already links styles.css. You are completing five TODOs, with no npm or build tools.

  1. Place a box-sizing: border-box reset first.
  2. Use a full-height column body and a flex main region that centers the form.
  3. Give the form padding, border, a max-width of 360px, and a flex column with gap.
  4. Choose a readable accent color for header and button backgrounds.
  5. Add a max-width: 480px query that removes main padding and the form’s max-width, border, and radius.
Lab 02 starter: bring your own syrupEdit · Run · Observe
Reveal complete Lab 02 solution
/* 1. Reset */
*, *::before, *::after { box-sizing: border-box; }
body {
  margin: 0;
  min-height: 100vh;
  display: flex;
  flex-direction: column;
  font-family: system-ui, sans-serif;
  color: #2e1732;
  background: #fff9ed;
}
/* 2. Layout */
header, footer { padding: 16px 24px; }
header { background: #713b65; color: white; }
main {
  flex: 1;
  display: flex;
  justify-content: center;
  align-items: center;
  padding: 24px;
}
/* 3. Components */
form {
  width: 100%;
  max-width: 360px;
  padding: 32px;
  border: 2px solid #ddc8a9;
  border-radius: 20px;
  background: white;
  display: flex;
  flex-direction: column;
  gap: 16px;
}
.field { display: flex; flex-direction: column; gap: 6px; }
input, button { font: inherit; }
input { width: 100%; padding: 10px; border: 1px solid #8b748e; border-radius: 6px; }
button { padding: 12px; border: 0; border-radius: 8px; background: #713b65; color: white; }
input:focus-visible, button:focus-visible { outline: 3px solid #a36612; outline-offset: 3px; }
/* 4. Responsive overrides */
@media (max-width: 480px) {
  main { padding: 0; }
  form { max-width: none; border: none; border-radius: 0; }
}

Keep the stylesheet easy to change

Use classes for styling; keep IDs for unique identity and label or script hooks. Order styles as reset, layout, components, then responsive overrides. Name classes for their purpose, such as .field, rather than their current color. Keep unit choices consistent, and use !important sparingly.
