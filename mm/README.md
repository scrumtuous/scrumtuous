# Angular Week: The Full Stack Breakfast Club
Extract the entire ZIP, then open index.html. Keep pages/, assets/, labs/ and resources/
together so all relative links work. No CDN is needed for the Bootstrap navbar.
All 11 completed lesson pages are in pages/. They cover Modules 01–11 and 13–15,
with 05–06, 07–08 and 10–11 combined. Modules 12 and 16 were not supplied as completed pages.
The landing overview follows the supplied Week 10 / Sprint 9 PDF in resources/.
Lesson images, editable snippets, quizzes and lab downloads are preserved.
Angular/backend source examples require their actual toolchains and services;
offline browser teaching models are labeled within lessons.
The navbar uses Bootstrap 5.3.8, bundled locally with its MIT license.
Bootstrap CSS is scoped to the navigation header so it does not restyle lesson content.
