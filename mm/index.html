Your learning journey

From backend knowledge to a working interface.

The overview places Angular after Node.js, NestJS and authentication, and before applied project work and cloud deployment. This sprint brings your existing services into a user-facing experience.

Node.js / NestJS & AuthenticationUI Development with AngularApplied Project WeekCloud, Deployment & Final Showcase
Mission for the week

Make the full stack visible.

  • Build the login journey, dashboard, order ticket and blotter.
  • Generate typed clients from OpenAPI specifications and connect the UI to live backend services.
  • Cover core user journeys with meaningful unit tests and Playwright end-to-end tests.
  • Keep JWT interceptors, route guards and output encoding against XSS in view as you build.

These are the sprint goals from the supplied overview PDF. This collection includes the 13 completed pages covering Modules 01–11 and 13–15. Dedicated Module 12 (OpenAPI clients) and Module 16 (testing) lessons are not included; they remain roadmap goals here.

Build reactive views

Use standalone components, templates and signals. Understand which state is shared and how immutable updates keep derived values correct.

Connect real journeys

Join forms, HTTP, routing and authentication so a user can log in, navigate and submit an order with useful feedback.

Prove it works

Use lab checks, Network evidence and before-and-after database queries. Extend these journeys with the sprint’s unit and end-to-end testing goals.
